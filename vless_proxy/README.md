# VLESS SOCKS Proxy

Private, TCP-only SOCKS5 proxy for selected Home Assistant integrations through
a VLESS outbound powered by Xray-core.

The endpoint is restricted to Home Assistant's internal app network and is not
published to the LAN. Red Shield VPN VLESS + REALITY links are tested, but the
project is provider-independent and is not affiliated with Red Shield VPN.

Open the **Documentation** tab after installation.
